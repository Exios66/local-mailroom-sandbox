# Merger critical-field admission

Sixteen populated fields on three agreements are admitted from independent source-only label
and check passes. A separate source review verifies the relevant sections and records the
actual ranges read. Four formal review decisions retain the cash exceptions, fee triggers and
base exchange-ratio adjustments. The ratio adopts the check pass's adjustment quote.

`INDEX.json` identifies the pinned source, admission code and exact input hashes.
`submissions/` preserves byte-identical raw passes, admission projections and review decisions.
Projection changes only the selected field keys; values, evidence, identities and supplementary
notes are unchanged. `source-review.json` records raw UTF-8 offsets with BOM and CRLF preserved.
`admission-audit.json` verifies missing-only admission, runtime fields, prepared truth, real
per-field scoring events and preservation of preceding catalog and overlay payloads.

`disposition.json` keeps all twelve unadmitted assignments and their reasons. Truncated-source
gaps, conditional outside dates, a cash/mixed source-fit conflict and one-sided absence answers
remain unresolved. No source subtype or absence is inferred.

These are machine near-gold labels with `use_as_truth: false`. The per-field events establish
scoring eligibility; they do not measure model performance or improve the separate MAUD headline.
No Hub revision, production selector, experiment lock or staged release is changed.
