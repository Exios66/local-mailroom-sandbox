## Highlights

This release covers the work since v0.3.0 (2026-10-17). It carries the **rb1 evaluation
runbook** (SAND-108: split runbook-v2 on dataset v9.3, Phase 0 gates, the campaign report
tree and the H5 LLM-sorter vs decision-model comparison), the **Decisions-API reviewer and
extraction gate** (SAND-085), the **production slice gate and staged label overlays**, the
**hotfix layers** for the vendored pipeline (`HF-001`–`HF-017`) and scorer
(`SHF-001`–`SHF-016`), and a **documentation reorganization** with drift tests that keep it
current.

### Models, serving and routing

- **Qwen3.5-9B is the default model** (SAND-077) on `modal-vllm`, `vllm-local` and
  `vllm-remote`, with `qwen/qwen3.5-9b` as the OpenRouter twin; a larger judge on Modal
  (SAND-078) and stronger specialist tiers (`--specialist-tier mid|full`, SAND-079).
- **OpenRouter runs are first-class and bounded.** Routing loops are bounded, API extractions
  are no longer cut off at the L4 output cap, OpenRouter never chunks a long document
  (HF-009, HF-010), the judge and arbiters read a long document whole, and preflight
  refuses an OpenRouter run that would fall back to the Modal/L4 input budgets.
- **Judge and arbiter paths always end.** A judge is asked once more after a parse failure
  (HF-002, HF-013), high extraction confidence no longer skips the judge (HF-007), and an
  arbiter with no re-extraction budget gives a final ruling (HF-015).

### Reviewer, decisions and gates

- **Decisions-API reviewer** (`openai/gpt-6-luna-decisions`, SAND-085) with frozen question
  sets in `config/decisions/` (byte-hashed into each run lock), calibration and held-out
  validation runs, and reviewer reports under `reports/decisions/`.
- **Extraction gate** (`task: extraction_gate`): a Decisions-API reviewer of a specialist's
  extraction, with question sets up to 1.3.0 vetted field by field.
- **Production slice gate** (#305): nested slices of the dataset scored against a pinned,
  hash-checked staged label overlay (production on `9.3.1-rc.9`).

### Scoring and labels

- **Scoring hotfixes are dual reported**: every scored row keeps the raw Dojo-pin value
  under `raw_dojo` beside the hotfixed headline. New this cycle: stale Hub labels are no
  longer scored as truth (SHF-015), and an empty-universe CUAD contract row is scored on
  its reviewed labels instead of being unscoreable (SHF-016).
- **Near-gold contract labels** for the 61 empty-CUAD contract rows, and the regenerated
  v9.3 label-repaired release.
- **`sandbox rescore`** re-scores a finished run's stored answers against other truth, with
  no model call. **Pain-point composites** score pipeline runs per document and experiment.
- The Dojo source order is installed release (`requirements/dojo-release.txt`), then a
  selected verified cache, then the vendored snapshot, which is at `7d69bbd` (`main` after
  llm-dojo-scoring #185, untagged). SHF-014 is retired by that refresh.

### Operator tooling

- **Pipeline floor viewer** (`sandbox floor`): live history, simulated replay, a document
  panel showing what each agent read, and confusion-cell isolation.
- **`sandbox autoresearch`**: a config-only greedy lever search over locked runs with a
  held-out confirmation run.
- **`sandbox api`** client for a running mailroom API plus the selected Dojo, and
  **`sandbox review`** for parked documents.
- A run ledger of every paid run that passed the spend gate, key-headroom and API token
  spend ceilings (SAND-089), and named Modal images.

### Documentation

- `docs/README.md` indexes every page. Designs moved to `docs/design/<ticket>/`, audits are
  dated under `docs/audits/`, superseded notes are in `docs/archive/`, and research notes
  are in `docs/research/`.
- README has a Hotfixes section, every top-level command and a full layout map;
  `AGENTS.md`, `reports/README.md` and `scripts/README.md` were brought up to date.
- `tests/test_docs_drift.py` fails CI when a page is not indexed, a hotfix or command is
  undocumented, the layout contract misses a directory, or code cites a missing docs path.

## Compatibility notes

- **Extraction headlines move across SHF-015 and SHF-016** on `corporate_record`,
  `correspondence`, `insurance_claim` and empty-CUAD contract rows. Rescore older runs that
  stored per-document answers (`sandbox rescore`) before comparing, or compare the per-item
  `raw_dojo` values; see `docs/scoring-hotfixes.md`.
- **The family dataset pin is Hub tag v9.3**, and the rb1 campaign uses split runbook-v2.
  Runs locked on earlier revisions keep their pins.
- **Moved paths.** Design docs moved under `docs/design/`, nine superseded chat-model
  reviewer configs moved to `config/runs/legacy/`, and retired campaign scripts moved to
  `scripts/archive/`. Old doc paths are listed in `tests/test_doc_paths.py`.
- The `sandbox` package version is now **0.4.0**.
