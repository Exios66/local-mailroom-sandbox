# Merger election and other subclass admission

Thirteen previously missing populated fields on two agreements pass independent source-only
label/check validation and a separate source adjudication. The additions include contracting
parties, parent and target identities, actual signers, the governing-law exception, and base
cash/election terms. Three formal decisions retain share exclusions, election, proration and
adjustments; the $58 cash value adopts the check quote with its explicit exceptions.

`INDEX.json` records source and code revisions, hashes, admission counts and exact projection
proof. `submissions/` contains byte-identical raw passes, the selected field projections and
review decisions. `source-review.json` records actual inspected source ranges and 36 verified
quotes with raw UTF-8 character and byte offsets, preserving BOM and CRLF. The original passes
and adjudication are scoped; they do not claim full-document annotation.

`admission-audit.json` confirms all thirteen additions match prepared truth, are registered
runtime fields and produce field-scoring events. All 10,660 preceding catalog rows, 1,899
supplementary rows and 9,755 overlay field payloads are preserved. The resulting overlay has
9,768 labels. The separate MAUD headline is unchanged; this is static eligibility evidence.

`disposition.json` keeps three assignments unadmitted. One exchange-ratio search remains
unfinished; two party/subsidiary fields conflict between preamble and execution names. No
absence or identity correction is inferred. These are machine near-gold labels with
`use_as_truth: false`, not human gold. Production remains on rc.10 with frozen locks unchanged.
